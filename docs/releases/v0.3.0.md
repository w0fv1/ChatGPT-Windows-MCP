# v0.3.0 — 系统托盘与静默启动

## 新增功能

- 显示器样式的托盘图标，通过状态圆点区分停止、处理中、就绪、待确认和故障。
- 左键托盘图标恢复主窗口；右键菜单提供当前状态、显示主窗口、启动／停止服务、打开日志和退出。
- 在 **高级选项 → 运行设置 → 开机自启下方** 新增“静默启动”，默认关闭，设置保存后下次启动生效。
- 开启静默启动后，手动启动和 Windows 登录自启都会直接进入托盘并连接已保存的服务，不闪现主窗口。配置未完成或托盘不可用时仍显示窗口。
- 后台启动失败时使用托盘通知，点击通知或托盘图标可打开窗口查看日志并重试。

## 行为变化

**关闭窗口现在会收起到托盘，服务继续运行。要停止服务并退出程序，请右键托盘图标，选择“退出”。** 首次关闭窗口时会显示说明通知。

## 下载与升级

- `ChatGPT-Windows-MCP-win-x64.zip`：完整便携版，包含运行依赖。
- `ChatGPT-Windows-MCP-online-win-x64.zip`：在线便携版，首次运行按需下载依赖。
- `SHA256SUMS.txt`：两个压缩包的 SHA-256 校验值。

退出旧版后，将新版解压到原目录，保留原有 `config.json`。现有开机自启设置继续有效；静默启动默认关闭，可按需开启。

## 验证

Release 编译将警告视为错误。发布流程运行 52 项现有回归测试及新增 Windows 托盘生命周期测试，覆盖设置保存、配置未完成时显示窗口、收起与恢复、最小化恢复、静默启动派发和隐藏状态下退出清理。上传文件下载校验一致后才公开发布。

托盘测试不会连接真实账户；实际 Windows 注销／重启、通知显示和真实 Tunnel 连接仍需在目标环境验证。
