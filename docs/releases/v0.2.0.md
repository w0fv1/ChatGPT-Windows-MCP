# v0.2.0

这次更新主要解决首次启动下载依赖失败、配置向导步骤不清楚和启动状态反馈不足的问题。

## 完整内置运行环境

- 内置 uv/uvx 0.12.21、Python 3.13.14、Windows-MCP 0.8.5 及全部 92 个依赖包。
- 内置 Tunnel 客户端 v0.0.15 和配套 cloudflared，发布包包含 .NET 运行环境。
- 默认配置首次启动只需本地校验和释放文件，无需 WinGet、App Installer 或预先安装 Python。
- 连接 OpenAI 仍需联网；手动指定其他运行环境版本可能需要下载。

## 配置与插件创建

- 按 Tunnel → API Key → 代理 → 插件的顺序完成配置，进入插件页自动启动 MCP 和 Tunnel。
- 提供两种方式：手动在 ChatGPT“添加 → 创建 MCP 应用”，或复制提示词交给 @Plugin Creator。
- AI 创建提示词中的应用详情链接为可选项；AI 缺少 Tunnel 注册能力时会提示手动步骤，不创建占位插件。
- 打开页面由用户点击触发，并提供链接、Tunnel ID 和提示词复制按钮。
- 点击“完成配置”后检查配置、MCP 工具列表、Tunnel ID 和隧道就绪状态；通过后回到主页，失败留在向导重试。

## 进度与日志

- 当前操作和百分比显示在同一行，不显示加载图标或进度条。
- 内置环境校验与解压按实际文件处理进度更新，避免长时间停在 35%。
- 日志即时写入启动步骤、进程输出、耗时和完整错误，并隐藏敏感凭据。

## 下载与验证

下载 `ChatGPT-Windows-MCP-win-x64.zip`，解压后运行 `ChatGPT-Windows-MCP.exe`。使用同目录的 `SHA256SUMS.txt` 校验压缩包。

本地验证：51 项回归检查通过；在全新目录、空 PATH 和不可用下载代理下成功启动内置 MCP 并发现 20 个工具；内置文件损坏修复、解压进度和完成配置失败重试检查通过。ChatGPT 端应用创建状态仍需在 ChatGPT 中确认。
