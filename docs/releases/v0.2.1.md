# v0.2.1 — 开机自启

## 新增功能

- 在 **高级选项 → 运行设置** 中新增“开机自启”开关，默认关闭，修改立即生效，无需管理员权限。
- 配置向导点击“完成配置”、服务连接检查通过后，询问是否开启开机自启。选择“否”保持关闭；已开启、配置失败或取消时不重复询问。
- 开启后，当前用户登录 Windows 时自动打开程序，并使用已保存的配置启动 Windows-MCP 和 Tunnel。配置未完成时仅打开主页。
- 手动启动仍保留原来的操作流程；关闭窗口仍会停止服务。

## 下载与升级

- `ChatGPT-Windows-MCP-win-x64.zip`：完整便携版，包含运行依赖。
- `ChatGPT-Windows-MCP-online-win-x64.zip`：在线便携版，首次运行按需下载依赖。
- `SHA256SUMS.txt`：两个压缩包的 SHA-256 校验值。

退出旧版后，将新版解压到原目录，保留原有 `config.json`。请在固定目录中开启自启；移动程序后需在新位置重新开启，删除前请关闭。同一用户仅注册一份便携程序。如果在 Windows 任务管理器中禁用了启动项，请在那里重新启用。

## 验证

Release 编译按警告视为错误执行，回归测试包含自启项添加、移除、带空格和中文路径，以及多份便携程序的自启归属。发布流程会重新构建并运行测试，下载已上传的发布文件校验一致后再公开发布。

实际 Windows 注销/重启和真实账户的完整 Tunnel 连接仍需在目标环境验证。
