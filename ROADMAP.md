# Roadmap

## Near term

- Add automated unit tests around configuration, proxy selection, and process-state transitions.
- Add a first-class diagnostics view for DNS, IPv4/IPv6, proxy source, MCP reachability, and Tunnel metadata status.
- Improve credential storage while keeping portable operation practical.
- Add signed release artifacts and checksums.

## Later

- Localization beyond Chinese/English.
- More granular Windows-MCP tool exposure profiles.
- Better update UX for the launcher and tunnel-client.
- Accessibility review and keyboard-navigation improvements.

Roadmap items are directional rather than commitments. Open a feature request to discuss design before implementing large changes.
