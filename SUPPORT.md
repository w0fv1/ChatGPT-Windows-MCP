# Support

For usage questions, setup problems, or connection troubleshooting, use GitHub Discussions when enabled. For reproducible software defects, open a bug report with logs that have been reviewed for secrets.

Before opening an issue:

1. Confirm you are using the latest release.
2. Run the built-in connection diagnosis.
3. Remove Runtime API Keys, private Tunnel IDs, usernames, local paths, and other sensitive information from logs.
4. Include Windows version, app version, and the exact failure stage.

Security vulnerabilities belong in the private process described in [SECURITY.md](SECURITY.md), not in public issues.
